# vn-farm

Раннер для параллельного кодирования видео на GitHub Actions.

- `farm/runner.js` — выполняет одну задачу (кусок видео или аудио/превью) и выходит.
- `.github/workflows/farm.yml` — запускается только через `workflow_dispatch` внешним диспетчером.

В репозитории нет адресов, ключей и данных: всё приходит из GitHub Secrets (`FARM_URL`, `FARM_KEY`)
и от диспетчера по одноразовому тикету. Логи маскируют идентификаторы.
